# Academic-Automation - Student Performance Categorization Based on Marks

## Purpose and Need:
As Unit tests, Insemester Examinations are conducted in the institute.  I observed that we frequently spend significant time manually identifying student categories such as Fast Learners, Average Learners, and Slow Learners to list out slow learners and fast learners. This is a crucial activity to monitor academic progress, but it often demands substantial time and effort from faculty members. This process is carried out in two different ways:
- Manually categroize the students based on Marks
- Using excel sheet, filter out the students.

In both approaches time required is nearly 20-30 minutes.

## Key Benefits of the Application:
The developed automation application is designed to minimize the time required for this classification task, ensuring accuracy and efficiency.

Time Savings: The manual process, which previously took 20-30 minutes, can now be completed in just 7-10 seconds.

**Effort Reduction:**

Total Employees Involved: 100

## Impact:
This application will not only enhance productivity but also ensure accuracy and consistency in identifying slow learners and fast learners. It is a step towards leveraging technology for educational improvement and making our academic processes more efficient.
